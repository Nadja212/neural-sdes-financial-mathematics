# Master's Thesis: Neural Stochastic Differential Equations in Financial Mathematics

## Project Overview

This repository contains the code, documentation, and supplementary materials developed as part of the master's thesis entitled *"Neural Stochastic Differential Equations in Financial Mathematics"*.

The aim of this project is to better understand the efficiency and practical applicability of neural networks within the frame of SDEs in financial mathematics.

The repository supports the methodological transparency and reproducibility of the research presented in the thesis.

## Research Context

**Master's thesis:** Neural Stochastic Differential Equations in Financial Mathematics  
**Author:** Nadja Niederberger  
**Institution:** Johannes Kepler University Linz  
**Degree programme:** Computational Mathematics  
**Year:** November 2026

## Methodology

The project follows the methodological approach described in the master's thesis.

The main steps are:

1. Data collection through Monte Carlo Simulation
2. Implementing Neural Networks and Training
3. Comparison real and trained Values

Further methodological details are provided in the corresponding chapters of the thesis.
